## 一、项目概述

### 1.1 物理背景

复现论文 [J-PINN (Materials & Design 2026)](https://doi.org/10.1016/j.matdes.2026.116567) 的核心架构：4 区域分解 PINN + PDE 残差 + 接口缝合。本项目用 2D Laplace 方程（稳态热传导）替代论文的 Navier-Cauchy（弹性力学），因缺原版 DIC 数据。

### 1.2 输入输出

| 项 | 内容 |
|---|---|
| 输入 | (x, y) ∈ [-1, 1]²（归一化） |
| 输出 | T̃(x, y) ∈ [-1, 1]（归一化标量温度）|
| 真实解 | log(r_hot) - log(r_cold) + 2·tanh(50y)·𝟙[|x|<0.5] |
| 物理场 | T ∈ [-5, 5]（去归一化）|

### 1.3 模型变体（消融）

| 变体 | 子网数 | hidden | 隐藏层 | 参数量 |
|---|---|---|---|---|
| `JPINN`（full） | 4 | 64 | 4 | 70,148 |
| `TwoRegionPINN` | 2 | 64 | 4 | 35,074 |
| `SingleRegionPINN` | 1 | 128 | 5 | 84,609 |

### 1.4 训练范式

- 优化器：Adam（论文原选）
- LR 调度：CosineAnnealingLR(T_max=epochs, eta_min=1e-6)
- 精度：float64
- 设备：CPU 默认
- 每 epoch 重新采样配点（论文 §2.3）
- 干跑验证 + NaN 守卫

## 三、核心模块

### 3.1 模型（`models/pinn_core.py`）

| 类 | 角色 |
|---|---|
| `MLPBlock` | 单 FNN 子网络（4 隐藏层 × 64 神经元 + SiLU）|
| `JPINN` | 4 区域主模型 |
| `TwoRegionPINN` | 上下分割消融 |
| `SingleRegionPINN` | 单区域消融 |
| `build_model(ablation)` | 工厂函数 |

### 3.2 损失（`losses.py`）

| 函数 | 角色 |
|---|---|
| `pde_residual` | ∇²T 计算 |
| `pde_loss` | ∇²T MSE |
| `interface_loss` | 3 条缝合 seam MSE |
| `bc_loss_dirichlet` | 外边界 Huber |
| `neumann_crack_loss` | 裂纹段法向跳跃 Huber |
| `smoothness_loss` | Sobolev Hessian |
| `LossAggregator` | 按权重汇总 |

### 3.3 数据（`data/`）

| 模块 | 角色 |
|---|---|
| `generate_synthetic_thermal_data` | 解析场生成 → .npz |
| `dataset.ThermalDataset` | 加载 + 配点 batch 采样 |
| `comsol_png_loader` | STUB，预留 COMSOL 接入 |

### 3.4 工具（`utils.py`）

| 函数 | 角色 |
|---|---|
| `region_id(x, y)` | 4 区域 ID 映射 |
| `sample_interior` | 4 区域拉丁超立方 |
| `sample_boundary` | 4 条外边 |
| `sample_interface` | 3 条缝合 seam |
| `sample_crack` | 裂纹段两侧 |
| `normalize_to_unit` / `denormalize_from_unit` | 归一化 |

## 六、常见问题

| 问题 | 原因 | 解决方案 |
|---|---|---|
| 训练 NaN | 边界冲突 / LR 过大 | 降低 lr 至 1e-4；或检查 boundary_target |
| 参数量不对 | n_hidden_layers 设错 | 检查 hidden vs n_hidden_layers 语义 |
| 调和性偏差大 | 中心差分失效 | 用 torch.autograd 而非 finite difference |
| 可视化崩 NameError | denormalize 变量名错 | 检查 `v_norm` 而非 `v` |
| 消融 E₂ 不合理 | 不同 ablation 用不同 λ 训练 | 用统一 λ 重训全部 |
| checkpoint 加载失败 | state_dict key 不匹配 | 确认 ablation 一致；`build_model` 重建 |
