# 快速配置指南

> J-PINN 首次使用必读 | 10 分钟快速上手
> 版本：0.1 | 更新：2026-08-13

---

## 一、环境准备

### 1.1 硬件要求

| 硬件 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | 现代 x86_64 / ARM64 | 4 核+ |
| 内存 | 8 GB | 16 GB |
| 存储 | 1 GB（不含数据）| 5 GB+ |

**GPU**：**不需要**。论文明确 CPU ~10× faster than GPU for ~72K 参数规模。

### 1.2 Python 环境

要求 Python 3.10+：

```bash
python --version
```

推荐使用 conda（`jpinn` 环境）：

```bash
conda create -n jpinn python=3.10 -y
conda activate jpinn
pip install -r requirements.txt
```

依赖列表（`requirements.txt`）：
- torch >= 2.0.0
- numpy >= 1.19.0
- scipy >= 1.5.0
- pandas >= 1.3.0
- matplotlib >= 3.3.0
- Pillow >= 9.0.0

## 三、生成数据

```bash
python data/generate_synthetic_thermal_data.py
```

输出 `data/synthetic_thermal.npz`（约 50 KB）：
- x_grid, y_grid: 200×200 坐标网格
- T_grid: 200×200 真实温度场
- T_smooth_grid: 调和分量（∇²T=0 自检用）
- region_id_grid: ∈ {0, 1, 2, 3}
- is_boundary_grid, is_crack_grid: bool 掩膜

**参数调整**：
```bash
# 100×100 网格（更小，冒烟用）
python -c "from data.generate_synthetic_thermal_data import main; main(N=100)"
```

## 四、训练

### 4.1 默认训练（5000 epoch，约 64 分钟）

```bash
python train.py --epochs 5000
```

输出：
- `checkpoints/jpinn.pt`：模型权重
- `logs/train_history.csv`：每 epoch 损失分量
- 控制台每 500 epoch 打印一行

### 4.2 快速冒烟训练（100 epoch，约 1.5 分钟）

```bash
python train.py --epochs 100
```

验证整条 pipeline 通畅；用于调参实验。

### 4.3 消融训练（3 个变体各 5000 epoch）

```bash
python train.py --ablation single --epochs 5000 --out checkpoints/single.pt
python train.py --ablation two    --epochs 5000 --out checkpoints/two.pt
# full 已训：checkpoints/jpinn.pt
```

总时长约 **4.5 小时**。建议后台跑。

### 4.4 自定义超参

```bash
python train.py \
    --epochs 5000 \
    --lr 5e-4 \
    --N_int 5000 \
    --lambda_pde 200 \
    --lambda_neumann_crack 0.1 \
    --out checkpoints/custom.pt \
    --print_every 100
```

详见 [api.md §5](../dev_reference/api.md#5-训练入口-train)。

## 五、可视化

### 5.1 单 checkpoint（4 张图）

```bash
python visualize.py --checkpoint checkpoints/jpinn.pt
```

输出到 `logs/figures/`：
- `pred_vs_true_heatmap.png`：预测 / 真值 / |误差| 三联
- `loss_curves.png`：5 类损失 + total 的曲线
- `per_region_2x2.png`：4 区域独立预测

### 5.2 消融对比（柱状图）

```bash
python visualize.py \
    --compare checkpoints/single.pt checkpoints/two.pt checkpoints/jpinn.pt \
    --compare_labels Single Two FourRegions
```

输出 `logs/figures/ablation_compare.png`：E₂ 相对误差柱状图。

⚠️ **命令写在同一行**，不要用 `\` 续行（Windows 会解析出空路径）。

## 七、常见问题

| 问题 | 解决方案 |
|---|---|
| `python: command not found` | 用 `conda activate jpinn` 或 `python3` |
| `No module named torch` | `pip install -r requirements.txt` |
| 训练 NaN | 降低 `--lr 1e-4`；或提高 `lambda_pde` |
| 显存 OOM（GPU） | 强制 `--device cpu`（论文推荐 CPU）|
| 调和性自检偏差大 | 已修复，确保用最新 `data/generate_synthetic_thermal_data.py` |
| `NameError: name 'v'` | 已修复，确保用最新 `utils.py` |
| 消融 E₂ 不合理 | 详见 [CODE_BUGS.md §N-1](../CODE_BUGS.md)；重训 full 用新权重 |
