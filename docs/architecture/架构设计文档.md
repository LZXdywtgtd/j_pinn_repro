## 三、模型架构：4 区域 J-PINN

### 3.1 论文背景（[Materials & Design 2026, 10.1016/j.matdes.2026.116567](https://doi.org/10.1016/j.matdes.2026.116567)）

论文用 4 个独立 FNN + 区域分解 + PDE 残差 + 接口缝合 + Sobolev Hessian 正则 解决含裂纹 2D 弹性力学问题（Navier-Cauchy PDE）。

### 3.3 降维策略：本项目

| 论文术语 | 本项目 | 理由 |
|---|---|---|
| 2D Navier-Cauchy（弹性） | **2D Laplace ∇²T=0**（热力场） | 缺论文原版 DIC 数据；Laplace 保留"PDE 残差监督"特性 |
| 4 区域裂纹分解 | **4 区域象限分解 + 内部裂纹段** | 完整保留 J-PINN 架构贡献 |
| Interface stitching | **温度连续 + 裂纹段 Neumann 跳跃** | 类比缝合 |
| L_smooth Sobolev Hessian | 同款 | 防谱偏置 |
| L_bc Huber + Z-score | 同款 Huber | 对噪点鲁棒 |

### 3.3 子网络结构（[MLPBlock](models/pinn_core.py)）

```
Input: (x̃, ỹ) ∈ [-1, 1]²
   ↓
Linear(2 → 64) + LayerNorm + SiLU
   ↓
Linear(64 → 64) + LayerNorm + SiLU  ┐
Linear(64 → 64) + LayerNorm + SiLU  ├ 4 个隐藏层
Linear(64 → 64) + LayerNorm + SiLU  │
Linear(64 → 64) + LayerNorm + SiLU  ┘
   ↓
Linear(64 → 1)                       # 无激活（线性输出 T̃）
   ↓
Output: T̃ ∈ [-1, 1]
```

**关键决策**（论文 §4.2 选定配置）：
- 4 隐藏层 × 64 神经元（含输入投影+4隐藏+输出 = 6 Linear）
- SiLU 激活（论文对比 Tanh 后选择，裂纹尖端梯度流更稳）
- LayerNorm 而非 BatchNorm（更适合 PINN 小 batch）
- 参数量 **70,148**（论文 §2.3 报告 71,712；本实现含 LayerNorm 略偏多）

### 3.4 4 区域路由（[JPINN](models/pinn_core.py)）

```
域 Ω = [-1, 1]²
裂纹段 Γ_crack = {(x,0) : |x| ≤ 0.5}

A (0): x<0,  y≥0  →  mlp_A
B (1): x≥0,  y≥0  →  mlp_B
C (2): x<0,  y<0  →  mlp_C
D (3): x≥0,  y<0  →  mlp_D
```

Forward 路由策略：
```python
def forward(self, x, y, region_id):
    xy = torch.stack([x, y], dim=-1)        # (N, 2)
    out = torch.empty_like(x)               # (N,)
    for rid, mlp in enumerate(self.sub_nets):
        mask = region_id == rid
        if mask.any():
            out[mask] = mlp(xy[mask]).squeeze(-1)
    return out
```

### 3.5 缝合接口（3 条 seam，论文核心）

| Seam | 几何位置 | 区域对 | 拼接类型 |
|---|---|---|---|
| **A↔B** | x=0, y∈[0, 1] | (0, 1) | 温度连续（缝合） |
| **A↔C** | y=0, x∈[-1, -0.5] | (0, 2) | 温度连续（缝合） |
| **B↔D** | y=0, x∈[0.5, 1] | (1, 3) | 温度连续（缝合） |
| **裂纹段** | y=0, x∈[-0.5, 0.5] | (B, D) | **Neumann 跳跃（不缝合）** |

镜像采样偏移 ε=1e-3（避免两点完全重合时 autograd 数值爆炸）。

### 3.6 消融变体

| 变体 | 子网数 | hidden | 隐藏层 | 参数量 | 论文对应 |
|---|---|---|---|---|---|
| **JPINN**（full） | 4 | 64 | 4 | 70,148 | 论文主模型 |
| **TwoRegionPINN** | 2（上下分割） | 64 | 4 | 35,074 | 论文 §4.6 中间基线 |
| **SingleRegionPINN** | 1 | 128 | 5 | 84,609 | 论文 §4.6 单区域基线 |

注：消融对比因权重不一致**当前不严格可比**（详见 [experiment_reports/调参与算法工程指导文档.md](experiment_reports/调参与算法工程指导文档.md) §三）。

## 四、损失函数（5 类 + 聚合器，详见 [jpinn_core/losses.py](../../jpinn_core/losses.py)）

```
L_total = λ_pde · L_pde + λ_interface · L_iface + λ_bc · L_bc
        + λ_neumann_crack · L_neumann + λ_smooth · L_smooth
```

| 损失 | 公式 | 论文对应 | 默认 λ |
|---|---|---|---|
| L_pde | mean((∂²T/∂x² + ∂²T/∂y²)²) | L_pde (Eq.13) | **100** |
| L_interface | mean((T_l - T_r)²) over 3 seams | L_disp (Eq.15) | 10 |
| L_bc | F.smooth_l1_loss(T_pred, T_target) on 外边界 | L_bc (Eq.18/19) | 1.0 |
| L_neumann_crack | Huber((T_top - T_bot)/(2ε), dT_jump) | L_traction (Eq.16) | 0.05 |
| L_smooth | mean( (∂²T/∂x²)² + (∂²T/∂y²)² + 2(∂²T/∂x∂y)² ) | L_smooth (Eq.14) | 0（关闭） |

**关键设计**：λ_pde=100（vs 论文 1e-6）—— 论文 Navier-Cauchy 含混合二阶导数量级大；本项目纯 Laplace 量级 1+，必须放大主导训练。

## 五、数据流

```
generate_synthetic_thermal_data.py
   │ T_smooth (log) + T_crack (tanh)
   ↓
data/synthetic_thermal.npz
   │ x_grid, y_grid, T_grid, region_id_grid, is_boundary_grid, is_crack_grid
   ↓
ThermalDataset._load_synthetic()
   │ 计算 T_min/T_max + spec
   ↓
get_collocation_batch() 每 epoch 重采样
   │ interior (4 regions) + boundary (4 edges) + interface (3 seams) + crack (2 sides)
   ↓
LossAggregator (model, batch)
   │ 5 类损失 → 加权汇总
   ↓
train.py 主循环
   │ Adam + CosineAnnealing + 梯度裁剪 + CSV 日志 + checkpoint
   ↓
visualize.py
   │ 单 ckpt：预测/真值/误差三联 + 损失曲线 + 4 区域子图
   │ 多 ckpt：消融对比 E₂ 柱状图
```

## 六、检查点系统

格式（仿 v4 run_train.py:1071-1084）：
```python
torch.save({
    "model_state_dict": ...,
    "epoch": 5000,
    "ablation": "full",                    # "full" | "two" | "single"
    "loss_weights": {...},                 # LossWeights dict
    "n_params": 70148,
    "best_loss": 0.226,
    "ds_meta": {                           # 反归一化用
        "T_min": -4.9999,
        "T_max": 4.9999,
        "spec": {...},
    },
    "args": {...},                         # 完整 argparse
}, "checkpoints/jpinn.pt")  # 显式路径示例；v0.9 默认写入 outputs/<ablation>/<task_id>/model_best.pt
```

加载：
```python
state = torch.load("checkpoints/jpinn.pt", weights_only=False)
model = build_model(state["ablation"], dtype=torch.float64)
model.load_state_dict(state["model_state_dict"])
```

### 6.1 v0.9 结果管理（outputs/ 归档目录）

- 裸 `python train.py`（`--out` 未传）：自动生成 `outputs/<ablation>/<task_id>/`（task_id 含时间戳+PID），归档 `model_best.pt` / `train_history.csv` / `config.json` / `metadata.json`，并更新 `outputs/latest.json`（每 ablation 的最新 task_id）
- 显式 `--out` 路径（旧方式）仍兼容；路径已存在且无 `--force` → 拒绝覆盖
- `visualize.py` / `postprocess/run_j_integral.py` 的 `--checkpoint` 默认 None：自动解析 `latest.json`，无则报错
- `run_ensemble.py` 产物归入 `outputs/ensemble/<run_id>/seed_<seed>/`
