## 一、损失函数架构

J-PINN 有 5 类损失，由 `losses.LossAggregator` 按权重汇总：

```
L_total = λ_pde · L_pde + λ_interface · L_iface + λ_bc · L_bc
        + λ_neumann_crack · L_neumann + λ_smooth · L_smooth
```

### 1.1 5 类损失

| 损失分量 | 默认权重 | 计算 | 论文对应 | 量级 |
|---|---|---|---|---|
| `L_pde` | **100** | mean((∂²T/∂x² + ∂²T/∂y²)²) | L_pde (Eq.13) | ~1 |
| `L_interface` | 10 | F.mse_loss(T_l - T_r) over 3 seams | L_disp (Eq.15) | ~0.01 |
| `L_bc` | 1.0 | F.smooth_l1_loss(T_pred, T_target) on 外边界 | L_bc (Eq.18/19) | ~0.1 |
| `L_neumann_crack` | 0.05 | Huber((T_top - T_bot)/(2ε), dT_jump) | L_traction (Eq.16) | ~50（跳跃值大）|
| `L_smooth` | 0（关闭） | mean(Hessian Frobenius²) | L_smooth (Eq.14) | — |

### 1.2 λ_pde 必须主导训练

**论文对 Navier-Cauchy PDE 用 λ_pde=1e-6**（含混合二阶导 `∂²/∂x∂y` 量级 ~10000）。
**本项目用 λ_pde=100**（Laplace 纯 ∇² 量级 1）。

调小 λ_pde → PDE 残差不收敛（实测：λ_pde=1 时 5000 epoch 残差停在 1.7e-3）。
调大 λ_pde → 主导训练但可能压制其他损失（推荐 50~200 区间）。

### 1.3 λ_neumann_crack 必须很小

裂纹项 `2·tanh(50y)` 在 y=±1e-3 处 `(T_top - T_bot)/(2ε) ≈ 50`。
若 λ_neumann=0.5（默认初值），Neumann 项量级 25 主导总 loss。
**建议 λ_neumann ≤ 0.1**，本项目默认 0.05。

### 1.4 λ_interface

缝合 seam 两侧温度差理论上 = 0，但模型初期差异 ~0.1。
λ_interface=10 让其优先收敛，否则 A↔B 等 seam 会漂移。
**不建议 >50**（实测会抑制 PDE 学习）。

### 1.5 λ_smooth 默认关闭

Sobolev Hessian 含 3 个二阶导项 + autograd 二次求导，**计算开销 ~3x**。
裂纹尖端 ∇²T 极大值会**让 Hessian 爆炸**，训练不稳定。
**建议仅在 PDE 已收敛后**开启微调（λ_smooth=0.001）。

## 三、调参经验

### 3.1 BUG 历史（来自开发记录）

**Bug 1：调和性自检偏差大**
- 症状：max|∇²T| = 9.9e+03（中心差分 h=1e-3）
- 根因：log 调和源附近梯度爆炸，中心差分失效
- 修复：改用 `torch.autograd.grad` 二次求导；并排除源 0.05 半径内
- 验证：max|∇²T| < 1e-6 ✓

**Bug 2：参数量 35,844 ≠ 论文 71,712**
- 症状：4 区域 JPINN 实际参数 ~36K，仅论文一半
- 根因：n_layers 语义错（1 输入 + 2 中间 + 1 输出 = 4 Linear）
- 修复：改为 n_hidden_layers=4（1 输入 + 4 隐藏 + 1 输出 = 6 Linear）
- 验证：参数量 70,148 ≈ 论文 71,712 ✓

**Bug 3：denormalize NameError**
- 症状：`NameError: name 'v' is not defined`
- 根因：`denormalize_from_unit` 函数体误写 `v` 而非 `v_norm`
- 修复：改为 `0.5 * (v_norm + 1.0) * (v_max - v_min) + v_min`
- 验证：可视化正常运行 ✓

**Bug 4：PDE 残差不收敛**
- 症状：5000 epoch 后 L_pde 停在 1.7e-3（验证清单要求 < 1e-4）
- 根因：λ_pde=1.0 不够主导（论文对 Navier-Cauchy 用 1e-6 是因量级不同）
- 修复：λ_pde 改 100，Neumann 项调小（λ=0.05，dT_jump=50）
- 验证：L_pde 主导训练 ✓

**Bug 5：消融对比不公平**
- 症状：E₂ Single=20.9%, Two=30.1%, Four=22.4%
- 根因：Full 用旧 λ_pde=1 训练，Single/Two 用新 λ_pde=100
- 决策：建议重训 Full 用 λ_pde=100 拿公平对比

### 3.2 调参场景建议

| 场景 | 建议 |
|---|---|
| 训练发散（NaN） | 降低 λ_pde 至 10；或 lr 至 1e-4 |
| PDE 残差停 1e-3 | 提高 λ_pde 至 200 |
| 缝合 seam 漂移 | 提高 λ_interface 至 30 |
| Neumann loss 不降 | 检查 dT_jump 值（应为 50 而非 100）；或增大 λ_neumann |
| 单区域 loss 不收敛 | 预期行为（论文 §4.6）— 验证消融趋势用 |
| 显存不足 | 降低 N_int 至 1000 |

### 3.3 与论文 §4.6 的差异

| 项 | 论文 | 本项目 | 原因 |
|---|---|---|---|
| 训练时长 | ~58 min（CPU 20K epoch）| ~64 min（CPU 5K epoch）| 合成数据收敛快 |
| LR 调度 | 比例 loss | CosineAnnealing | v4 范式，更稳 |
| 损失权重 | NTK 自动 | 手动量级分析 | NTK 不稳（论文结论） |
| 浮点精度 | float64 | float64 | 一致 |
| 数据 | FEM/DIC | 合成 + 后续 COMSOL | 缺原版数据 |

## 五、边界 outlier 移除（P2，论文 §3.3 Eq.19-20）

### 5.1 算法

```
对每个外边界点维护残差平方 (T_pred - T_target)² 的 EMA（α=0.1）
burn-in 后（Γ=100 epoch）每 edge 内：
  μ = median(EMA)，σ = 1.4826 · MAD(EMA)   # 中位数 + MAD 稳健估计
  Z_i = |EMA_i - μ| / (σ + ε)
  Z_i > δ=3.0 → 标记 outlier，从 L_bc 排除
L_bc 除以 N_total / N_active 归一化
```

**为何用 MAD 而非 mean/std**：outlier 会拉高 σ，导致 Z 阈值失效（本实现测试暴露的问题）。MAD（median absolute deviation）对 outlier 鲁棒。

### 5.2 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--outlier_enabled` | 关 | 启用 P2 |
| `--outlier_burnin` | 100 | Γ 宽限期（前 Γ epoch 不评估） |
| `--outlier_delta` | 3.0 | δ 阈值 |
| `--outlier_ema_alpha` | 0.1 | EMA 平滑系数 |
| `--boundary_strategy` | resample | fixed（固定点）是 P2 持久 mask 的前提 |

### 5.3 使用

```bash
python train.py --outlier_enabled --boundary_strategy fixed \
    --outlier_burnin 100 --outlier_delta 3.0 --outlier_ema_alpha 0.1
```

### 5.4 论文对标

论文 Table 5：启用 Z-score outlier 移除后，L_bc 下降 88%（5.04e-2 → 1.05e-2）。本实现为 MAD 稳健版（论文用 mean/std，但本实现发现 mean/std 对稀疏 outlier 不敏感，故改 MAD）。

## 六、损失比例 LR 调度器（P17，论文 §3.4）

论文 §3.4 指出"learning rate annealing, decaying proportionally to the total loss"对稳定性关键。

### 6.1 算法

```
lr = base_lr * clip(loss / loss_ref, lr_min/base_lr, 1.0)
loss_ref 首次 step(loss) 时自动设为当前 loss
```

### 6.2 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--scheduler` | cosine | cosine / loss_prop |
| `--lr_min` | 1e-6 | LR 下限（loss_prop 用） |

### 6.3 使用

```bash
python train.py --scheduler loss_prop --lr_min 1e-6
```

### 6.4 与 CosineAnnealing 对比

| 项 | Cosine | loss_prop |
|---|---|---|
| 依赖 | 仅 epoch | total loss |
| 行为 | 预先衰减到 eta_min | 随 loss 下降成比例衰减 |
| 论文对标 | 本项目 v4 范式 | 论文 §3.4 原算法 |

## 八、论文 Table 2 权重映射（B14 文档化）

### 8.1 论文 Table 2 原值（MPa 物理单位 + Navier-Cauchy PDE）

| 权重 | 论文 Table 2 | 对应损失 |
|---|---|---|
| λ_pde | **1e-6** | Navier-Cauchy PDE 残差 |
| λ_disp | 1e-7 | Interface 位移连续 |
| λ_0 (= λ_bc) | 60 | 外边界 Dirichlet |
| λ_smooth | 0.01 | Sobolev Hessian 正则 |

### 8.2 本项目值（Laplace ∇²T=0 + 归一化域 [-1,1]²）

| 权重 | 本项目 | 对应损失 | 量级 |
|---|---|---|---|
| λ_pde | **100.0** | Laplace PDE 残差 | ~1.0（无量纲） |
| λ_interface | 10.0 | 缝合连续 MSE | ~0.01 |
| λ_interface_normal | 1.0 | L_traction 降维 | ~1.0 |
| λ_bc | 1.0 | 外边界 MSE/Huber | ~0.1 |
| λ_neumann_crack | 0.05 | Neumann crack 跳跃 | ~50（调小避免主导） |
| λ_smooth | 0.0（关）| Sobolev Hessian | Hessian 爆炸 |

### 8.3 量级偏差原因（核心）

**论文 vs 本项目在 4 个维度上不同**：

| 维度 | 论文 | 本项目 | 量级影响 |
|---|---|---|---|
| **PDE 类型** | Navier-Cauchy（含混合二阶导 ∂²/∂x∂y）| Laplace ∇²T=0 | 残差量级 ~1e4 vs ~1 |
| **域** | [0, 40]×[0, 25] mm（DCB）| [-1, 1]² 归一化 | 物理单位 vs 无量纲 |
| **输出** | 位移 u ~1e-3 m | 温度 T ~1（归一化）| 数值 ~1e-3 vs ~1 |
| **数据** | FEM/DIC 实测全场 | 合成 log 调和场 | 量级由合成函数决定 |

**结论**：论文 λ_pde=1e-6 是"残差量大 → 权重小"原则；本项目 λ_pde=100 是"残差量小 → 权重大"原则。
两者权重方向相反，但都是为了**让 PDE 项主导训练**。

### 8.4 调参区间建议

| λ | 推荐区间 | 偏离后果 |
|---|---|---|
| λ_pde | 50~200 | < 50 → PDE 不收敛；> 200 → 压制其他损失 |
| λ_interface | 5~30 | < 5 → 跨区域漂移；> 30 → 抑制 PDE 学习 |
| λ_bc | 0.5~5 | — |
| λ_neumann_crack | 0.01~0.1 | > 0.1 → Neumann 项量级 25 主导总 loss |
| λ_smooth | 0（默认关）| 启用 → λ=0.001 微调；Hessian 计算开销 ~3x |

### 8.5 反转条件（ADR-0001）

获得论文原版 DIC + 切换 Navier-Cauchy 时，必须重做权重量级校准：
- 建议按"λ ~ 1/残差量级"原则
- 论文经验值 λ_pde=1e-6 / λ_disp=1e-7 可作起点
- 详见 [docs/DECISIONS/0001-laplace-substitute.md §10.1.4](../DECISIONS/0001-laplace-substitute.md)
