## 一、问题背景

### 1.1 原始论文

Stamatelatos, Kotsinis, Binsfeld, Loutas. **"J-PINN: Adaptive domain-decomposed physics-informed neural network for fracture assessment"**. *Materials & Design*, 2026. DOI: [10.1016/j.matdes.2026.116567](https://doi.org/10.1016/j.matdes.2026.116567).

论文解决 **2D 含裂纹弹性力学** 问题：
- 域：含水平穿透裂纹的平板
- PDE：Navier-Cauchy 平衡方程（应变-位移关系 + 平面应力/应变本构）
- 输出：位移场 (ũ, ṽ)
- 4 个独立 FNN 区域分解（A/B/C/D 对应裂纹 4 象限）
- 接口缝合：3 条 stitched + 裂纹 2 面 traction-free

### 1.2 复现动机

团队缺少论文原版 DIC 数据，无法直接复现；同时团队已有 COMSOL 2D 温度场数据可做交叉验证。

### 1.3 降维策略

| 维度 | 论文 | 本项目 |
|---|---|---|
| PDE | Navier-Cauchy（弹性，含混合二阶导） | **Laplace ∇²T=0**（稳态热传导） |
| 域 | 含裂纹平板 | 内部裂纹段 [x∈-0.5, 0.5]@y=0 |
| 输出 | 位移 (ũ, ṽ) | 标量温度 T(x,y) |
| 接口类型 | 位移连续 + 牵引力连续 | 温度连续 + 裂纹段 Neumann 跳跃 |
| 数据 | FEM 网格 / 实验 DIC | 解析合成场 + 后续 COMSOL PNG 加载 |

**保留 J-PINN 的核心架构贡献**：4 区域 MLP + PDE 残差 + 缝合 + Sobolev 正则 + Huber BC。

## 二、算法设计

### 2.1 4 区域分解（与论文保形）

```
         y=1 ┌─────────┬─────────┐
              │   A(0)  │  B(1)   │
              │ (左上)   │ (右上)  │
         y=0 ─┼─────────┼─────────┼─ x=0    x=1
              │   C(2)  │  D(3)   │
              │ (左下)   │ (右下)  │
         y=-1 └─────────┴─────────┘
              x=-1                x=1
                 ↑          ↑
        缝合 A↔B     裂纹段 (不缝合)
        缝合 A↔C ←── Γ_crack ──→ 缝合 B↔D
```

接口集合（与论文一致，第 4 条因裂纹不缝合）：
- `I_1`: A↔B @ x=0, y∈[0, 1]
- `I_2`: A↔C @ y=0, x∈[-1, -0.5]
- `I_3`: B↔D @ y=0, x∈[0.5, 1]
- `Γ_crack`: 裂纹段 @ y=0, |x|≤0.5（Neumann 跳跃）

### 2.2 合成数据场（解析解，已知 ∇²T=0）

```python
T_smooth(x, y) = log(r_hot) - log(r_cold)
    r_hot  = √((x + 0.6)² + (y - 0.5)² + 1e-4)
    r_cold = √((x - 0.6)² + (y + 0.5)² + 1e-4)

T_crack(x, y) = 2 · tanh(50y) · 𝟙[|x| < 0.5]

T(x, y) = T_smooth(x, y) + T_crack(x, y)
```

- T_smooth 严格调和（∇²T = 0 解析成立），可作 PDE 监督的 ground truth
- T_crack 在 y=0 处造成温度上/下半平面跳变，模拟论文裂纹间断

**调和性自检**（PyTorch autograd 二次求导）：排除源 0.05 半径内，max|∇²T| < 1e-6 严格成立。

### 2.3 4 区域独立 FNN

每个子网络：4 隐藏层 × 64 神经元 + SiLU + LayerNorm。
详见 [../architecture/架构设计文档.md §三](../architecture/架构设计文档.md#三模型架构4-区域-j-pinn)。

### 2.4 5 类损失函数

详见 [../architecture/架构设计文档.md §四](../architecture/架构设计文档.md#四损失函数5-类--聚合器-详见-lossespy)。

### 2.5 优化策略

- **优化器**：Adam（论文原选）
- **LR 调度**：CosineAnnealingLR(T_max=epochs, eta_min=1e-6)（沿用 v4）
- **精度**：float64（论文 §4.5：裂纹尖端需要更高精度）
- **设备**：CPU（论文 §4.5：CPU ~10× faster than GPU for ~72K 参数）
- **梯度裁剪**：max_norm=1.0（v4 风格）
- **干跑验证 + NaN 守卫**（v4 风格）

## 三、实验设计

### 3.1 消融实验（论文 §4.6 关键证据）

| 实验 | 子网数 | 参数量 | 预期 | 实际 |
|---|---|---|---|---|
| **Single** | 1（覆盖全域） | 84,609 | E₂ 高（论文：41%）| best_loss=24.93（Neumann 卡死） |
| **Two** | 2（上下分割） | 35,074 | E₂ 中（论文：32%） | best_loss=0.216 |
| **Full** | 4（4 区域） | 70,148 | E₂ 低（论文：0.91%）| best_loss=0.226（**旧 λ_pde=1 权重**） |

**当前局限**：Full 用旧 λ_pde=1 权重训练，Single/Two 用新 λ_pde=100，**不严格可比**。
建议重训 Full 用 λ_pde=100 获得公平对比（~64 min）。

### 3.2 训练时长

| 任务 | 设备 | 时长 |
|---|---|---|
| 5000 epoch full | CPU + float64 | ~64 min |
| 5000 epoch two | CPU + float64 | ~54 min |
| 5000 epoch single | CPU + float64 | ~154 min（更复杂 PDE 收敛慢） |
| 8 步冒烟测试 | CPU + float64 | ~30s |

### 3.3 验证清单

- [x] 数据 schema：x_grid, y_grid, T_grid, region_id ∈ {0,1,2,3}
- [x] 调和性自检：max|∇²T| < 1e-6（排除源近端）
- [x] 参数量 70,148（与论文 71,712 同量级）
- [x] 5 类损失能计算、无 NaN
- [x] 梯度反向传播正常
