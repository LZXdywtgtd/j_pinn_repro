### 3.5 Stage 4：Mode I/II 分解（B5 + C2）

**Commit**：`32a8a9e`

**修改**：`postprocess/j_integral.py` 新增 `j_integral_mode_decomposed` 函数（~117 行）

**算法**（Rigby-Aliabadi 对称/反对称分解）：
1. 同时评估 T(x,y) 与 T(x,-y)（裂纹面对称）
   - T_sym = 0.5 * (T(x,y) + T(x,-y))
   - T_asym = 0.5 * (T(x,y) - T(x,-y))
2. 对 T_sym / T_asym 求梯度 → σ_sym / σ_asym
3. J_I = ∮ (W_sym·n_x - σ_sym·n·∂T_asym/∂x) ds
4. J_II = ∮ (W_asym·n_x - σ_asym·n·∂T_sym/∂x) ds
5. 交叉项正交抵消（数学基础）：J ≈ J_I + J_II

**⚠️⚠️⚠️ 物理意义限制**（核心警示）：
- 论文 Mode I/II 描述弹性力学裂纹模式（法向张开 / 切向滑动）
- 本项目 Laplace ∇²T=0 降维后标量场无 Mode 概念
- σ_ij = ∇T·∇T^T 是几何外积（不是 Hooke 律应力）
- J_I / J_II 数值**不应**解读为 Mode 贡献

**保留用途**：
1. 验证 Rigby-Aliabadi 分解算法的数学正确性（正交性、路径无关）
2. 准备未来反转 ADR-0001 时直接复用（拿到 DIC 后）

**4 处重复警示位置**：
- 函数 docstring（`j_integral_mode_decomposed`）
- 文件顶部 docstring（`postprocess/j_integral.py`）
- `docs/dev_reference/api.md §8.1`
- `CHANGELOG.md` v0.7 Stage 4

**测试**：
- 线性场 T=a*x+0.5*y → J_I=1.0, J_II=0.17
- JPINN 随机初始化 → J_I+J_II=5.50

**反转条件**（ADR-0001 §11）：
- 获得论文原版 DIC 全场位移数据
- 切换 Navier-Cauchy PDE（恢复混合二阶导 + Lamé 参数）
- 届时 J_I / J_II 数值将恢复物理意义

**import 兼容**：try `from utils` / except `from ..utils`（v0.3 路径兼容）

#### B2: L_bc 归一化冗余移除
